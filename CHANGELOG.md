# Kinetica Ray Changelog

## Version 7.2.3.0 - TBD

-   Initial version.
-   Added `read_kinetica`/`write_kinetica` (Kinetica's native API, with
    parallel pagination on read and multihead ingestion on write) and
    `read_kinetica_sql`/`write_kinetica_sql` (DB-API 2.0, for arbitrary
    queries, JOINs, and inserting into an existing table).
